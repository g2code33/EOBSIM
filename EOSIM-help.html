EOSIM — Electronic Organ Bath Simulation

Start an experiment

Use New Experiment to choose a tissue preparation. Select a solution and use the reservoir and bath controls to manage the preparation.

Add a drug

Choose an agonist, antagonist or unknown, select its stock concentration and enter the volume to add. Use the corresponding Add button to apply it. Use the stimulation controls where relevant to the tissue.

Review and save

The chart displays the simulated response. Use its controls to change the displayed time range and inspect the trace. Use the File menu to save or reopen an experiment as an .EOB file. Printing and copying commands are available from the menu.

Dilution calculator

The calculator relates the stock solution concentration and volume added to the bath volume and final concentration.

This is a simulation for educational use, not a clinical or laboratory measurement device.
